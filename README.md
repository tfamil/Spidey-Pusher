# Spidey-Pusher
A borderless, always-on-top desktop overlay that reminds you to push your code to GitHub every day at 5:00 PM — Spider-Man-style.  Spider-Man descends from the top of your screen on a web line, lands, and a spider-web text panel asks:  DID YOU PUSH YOUR CODES IN YOUR GITHUB REPO?  You answer with YES or NO
